## What's in the database

All of it is in `supabase/migrations/`, applied in order:

| Migration | What |
| --- | --- |
| `…_init_schema.sql` | Tables, leaderboard views, row level security, privileges, realtime |
| `…_functions.sql` | Server-side logic (below) and the login trigger |
| `…_seed_data.sql` | Time rates, the 12 goals, 8 wheel prizes, 128 challenges. Generated by `scripts/gen-seed.py` |
| `…_fk_indexes.sql` | Two indexes the performance advisor asked for |
| `…_prize_win_label.sql` | Short prize phrases for the "Ultimele premii" list |

Tables: `timer`, `stats`, `rates`, `events`, `goals`, `viewers`, `watch_time`,
`prizes`, `spins`, `challenges`, `vote_rounds`, `round_challenges`, `votes`,
`suggestions`. Views: `leaderboard_gifts`, `leaderboard_bits`, `leaderboard_hours`.

**Who can do what**

- Visitors (logged out) can **read** public data: timer, stats, events, goals,
  rates, prizes, recent spins, challenges, rounds and tallies, watch-time
  leaderboard. They can't write anything.
- Logged-in viewers can also read their own viewer row, votes and suggestions,
  and call four functions: `cast_vote`, `suggest`, `spin`, `wheel_status`.
  Each checks who's calling (and, for votes and suggestions, that they're
  subscribed).
- Everything else (adding time, starting the timer, crediting watch time) is
  backend-only: Edge Functions with the service role, or the SQL editor.

**Functions**

| Function | Who | What |
| --- | --- | --- |
| `record_event(source, kind, external_id, user…, tier, quantity, currency, seconds)` | backend | The only way time is added. Dedupes on `external_id`, converts with `rates` (bits and donations proportional), doubles during "Ora dublă", updates stats and goals. Adds no time unless the timer is live. |
| `start_timer(seconds, scheduled_end)` | backend | Starts the subathon. |
| `freeze_timer(seconds)` | backend | "Îngheți timpul": the countdown stands still. |
| `set_double_hour(from, minutes)` | backend | Schedules "Ora dublă". |
| `credit_watch_time(viewers jsonb, minutes)` | backend | Chat presence → minutes → snowflakes (1 per hour, 2 for subs). |
| `cast_vote(round, challenge)` | subscriber | One vote per round; calling again moves it. |
| `suggest(body)` | subscriber | Challenge idea (3–140 chars, max 3 per 10 minutes). |
| `wheel_status()` | logged in | Snowflakes, spins available, time to the next snowflake. |
| `spin()` | logged in | The server picks the prize; the browser only animates to it. |

Tested on the live project inside rolled-back transactions: time and doubling
maths, dedupe, the login trigger, watch time and snowflakes, spin limits,
vote/move/closed round, subscriber-only checks, suggestion rate limit, and that
logged-out visitors can't write or call backend functions.

## Testing the live site without Twitch

From the SQL editor (or the Supabase connector) you can drive the page by hand:

```sql
select public.start_timer(3*86400, now() + interval '4 days');           -- go live
select public.record_event('twitch','sub','t1','1','test','test','3000'); -- a Tier 3 sub
select public.record_event('twitch','gift','t2','2','test2','test2','1000', 10);
```

Open https://fulgathon.github.io/ and it updates within a second. Reset afterwards:
delete from `spins`, `vote_rounds`, `events`; zero `stats`; set `timer` back to
`upcoming` with null times; clear `goals.unlocked_at`.

## Your steps: Twitch login

Secrets go in the dashboards, never in this repo or in chat.

1. **Twitch app.** At https://dev.twitch.tv/console (needs 2FA on the Twitch
   account) → *Register Your Application*:
   - Name: e.g. `FULGATHON`
   - OAuth Redirect URL: `https://yvbxtsuddjqqoogdoqrx.supabase.co/auth/v1/callback`
   - Category: *Website Integration*
   - Then *Manage* → copy the **Client ID**, click *New Secret* → copy the **Client Secret**.
2. **Supabase → Authentication → Sign In / Providers → Twitch**: turn it on,
   paste the Client ID and Client Secret, save.
3. **Supabase → Authentication → URL Configuration**:
   - Site URL: `https://fulgathon.github.io`
   - Redirect URLs: add `https://fulgathon.github.io/**` and `http://localhost:4321/**`
